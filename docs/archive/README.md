# Archive

These files describe the project as it was while it ran on Supabase, or are earlier plans. **They are out of date**
and kept only for history. For how things work now, read the files in `docs/` (start with `docs/architecture.md`),
and `convex/schema.ts` for the data model.

`supabase-sql/` holds the original database scripts from before the move to Convex.
